HOW TO READ THIS

A reference, not a universal edge.

Each finished image is encoded using the selected model’s VAE posterior mean. Those fingerprints define the original space. PCA gives us three display coordinates.

The wireframe surface is a convex hull around the reference points. It connects extreme points and includes gaps where no images were sampled.

Novelty is the average cosine distance to nearby reference fingerprints before PCA. The threshold is calibrated on held-out prompts. A high score means unusual relative to this collection, not unpromptable or unsafe.

VAE fingerprints retain spatial structure. Similar concepts can be far apart, and small shifts can affect distances. This is an experimental artistic explorer, not a validated semantic metric.

Existing images are encoded, not inverted to recover their original generation history. Models and encoding configurations have separate maps. Seeds improve repeatability within an environment; hardware and library changes can affect results.
